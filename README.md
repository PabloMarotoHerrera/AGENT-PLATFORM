# Agent Platform

Agentic workspace for architecture, research, products, platform code, external sources, and AI-agent collaboration.

## Canonical architecture

- `0_architecture/governance/` contains current governance decisions, operating contracts, and activation boundaries.
- `0_architecture/workspace/` contains workspace structure, responsibility, promotion, and documentation rules.
- `0_architecture/security/` and `0_architecture/validation/` contain the current security and validation models.
- `previusknowledge/docs/architecture/agent_*.md` retains the protected original agent taxonomy, organization, hierarchy, orchestration, execution, handoff, coordination, approval, role, capability, and authority architecture. Those originals are future architecture sources, not active runtime.
