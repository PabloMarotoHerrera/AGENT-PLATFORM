# Cognitive Semantic System Prototype Boundary

## Allowed Implementation
Allowed implementation is one minimal Python standard-library module that models cognitive entities, semantic claims, semantic relations, and substrate candidate records in memory, plus documentation that describes its boundaries.

## Forbidden Implementation
Forbidden implementation includes package manifests, lockfiles, tests, scripts, tools, CI, runners, CLI, runtime services, schedulers, worker loops, queues, reasoning engines, graph databases, vector databases, relational databases, ontology runtimes, embedding models, LLM integrations, persistence, source loaders, provider clients, API clients, MCP configs, credential stores, validation execution, security enforcement, product activation, and Graphify adoption.

## No Final Substrate Selection
The prototype does not select final Cognitive Semantic System substrate. Substrate remains deferred.

## No Graph Adoption
Graph remains candidate only. Graph candidate metadata is not graph adoption.

## No Graphify Adoption
Graphify remains evidence/historical/external/prohibited/candidate-evidence only and not authority. Graphify source is not inspected, migrated, adopted, or promoted.

## No Graph/vector/database/ontology Runtime
No graph database, vector index, relational database, document database, ontology runtime, embedding runtime, or persistence layer is created.

## No Reasoning Execution
Semantic relation registration is not reasoning execution. The prototype does not infer, traverse, rank, embed, reason, or decide.

## No Source Loading
The prototype does not load source files, source trees, product source, external source, datasets, models, artifacts, generated outputs, Graphify source, or unclassified `3_platform` contents.

## No Provider/API/MCP
No provider, adapter, API, network, authentication, or MCP activation occurs.

## No Tool Execution
No tools, shell commands, subprocesses, tests, scripts, package managers, builds, or scans are executed.

## No External Dependencies
The prototype uses Python standard library only. No graph, vector, ontology, database, embedding, LLM, provider, or Graphify dependency is introduced.

## No Product Activation
Products remain inactive. Product source remains local-only and is not copied into the prototype.

## Stop Rules
Stop if work requires target overwrite, final substrate selection, graph adoption, Graphify adoption, graph/vector/database/ontology runtime, source loading, reasoning execution, file access, network/API calls, provider/API/MCP activation, credential inspection, auth, package files, dependencies, test execution, product source inspection, existing `3_platform` inspection, Git mutation, or I-A start.
