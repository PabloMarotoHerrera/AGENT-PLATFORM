## Request Guidance

Use this blueprint only to draft memory update requests for human or governance review.

A memory update request should include:

| Field | Guidance |
| --- | --- |
| Requested change | State the proposed memory update in plain language. |
| Source refs | Cite accepted sources that support the request. |
| Authority posture | State that the request is non-authoritative. |
| Write posture | State that no memory write, GBrain sync, reindex, or promotion occurred. |
| Gate posture | Identify that a future memory authority gate is required before any write. |

Do not write GBrain memory, reindex memory, mutate operational memory, write normal user `.gbrain` or `.gstack` state, promote generated evidence, or sync memory.
