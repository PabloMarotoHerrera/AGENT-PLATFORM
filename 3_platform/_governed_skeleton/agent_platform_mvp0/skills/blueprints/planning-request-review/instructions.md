## Review Guidance

Use this blueprint only to structure a planning or ticket review before execution.

Review the request for:

| Check | Guidance |
| --- | --- |
| Objective clarity | Identify the requested outcome and whether acceptance criteria are explicit. |
| Scope boundaries | Identify allowed files, forbidden files, and blocked runtime surfaces. |
| Dependency posture | Identify required governance markers and any missing prerequisite. |
| Execution posture | Confirm that any execution remains blocked unless a future gate authorizes it. |
| Output posture | Classify output as review support only. |

Do not approve implementation, execute actions, write files, write memory, call providers, inspect credentials, or mutate Git.
