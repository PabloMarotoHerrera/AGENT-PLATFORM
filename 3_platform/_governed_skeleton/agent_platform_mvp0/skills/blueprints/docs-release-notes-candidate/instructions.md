## Drafting Guidance

Use this blueprint only to draft release-note or change-summary candidates from accepted records.

Drafts should include:

| Section | Guidance |
| --- | --- |
| Source refs | Cite accepted records used for the summary. |
| Change summary | Summarize what changed without claiming release approval. |
| Boundary notes | State that staging, committing, tagging, pushing, CI, publishing, and deployment remain blocked. |
| Command candidates | If commands are proposed, keep them as exact candidates for separate review and gate approval. |

Do not write release files, stage files, commit, tag, push, deploy, publish, run CI, call providers, or promote drafts to authority.
